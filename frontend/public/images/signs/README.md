# Ảnh từ điển ký hiệu

Đặt ảnh của mỗi chữ vào thư mục này, tên file trùng nhãn trong `public/model/labels.json`:

```
A.png  B.png  C.png  ...  Z.png
```

- Định dạng: `.png`, tên viết HOA.
- Nên dùng ảnh vuông (vd 400×400), nền sáng, bàn tay ở giữa.
- Chữ nào chưa có ảnh sẽ tự hiện hình vẽ minh họa, không bị lỗi giao diện.
- Mô tả cách tạo dáng tay của từng chữ nằm trong `src/signInfo.ts`.
